Seja bem-vindo(a) ao repositório do Sistema Musical, um projeto desenvolvido para a disciplina de Linguagens de Marcação. O objetivo principal aqui foi construir uma interface de gerenciamento musical completa, bonita e altamente semântica!

🖼️ Preview da Aplicação

🛠️ O que foi construído no projeto?

A aplicação conta com um painel principal (Dashboard) limpo e intuitivo para navegação do usuário (como o admin), dando acesso rápido às áreas centrais do sistema:

🎤 Gerenciar Artistas: Módulo para cadastrar, editar e organizar os cantores e bandas do sistema.

🎼 Cadastrar Músicas: Formulário estruturado para adição de novas faixas e metadados.

🎧 Biblioteca Musical: Painel completo para visualização, busca e filtragem de todo o acervo de músicas.

📑 Destaques Técnicos & Código

Estrutura HTML5 Semântica: Uso correto de tags como <header>, <main>, <section>, e <button> para garantirem acessibilidade e boa estrutura de documento (como o <!DOCTYPE html> no topo!).

Design Card-Based: Construção de cards estilizados com foco em experiência do usuário (UX), incluindo ícones visuais para identificação rápida de cada sessão.

Componentes de Controle: Botões funcionais de sessão (Sair) e identificação dinâmica do usuário logado.

🧰 Tecnologias Utilizadas

HTML5 (Estruturação semântica)

CSS3 (Estilização, layout flexível e design moderno)

Markdown (Documentação do projeto)
